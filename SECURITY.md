# Security

C10 Control is designed for a trusted local network.

- It has no authentication.
- It controls a speaker whose own API is unauthenticated on the LAN.
- It can serve files from folders you add as libraries.

Do not expose this app, or the speaker, to the internet. If you need remote access, put it behind a VPN.

Report a vulnerability privately through GitHub Security Advisories on this repository. Please do not open a public issue for a security problem.
